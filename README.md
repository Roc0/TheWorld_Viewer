# TheWorld Viewer

A self-contained procedural terrain demo that runs directly in a modern browser.

## Run

Open `index.html` in a browser. No build step or external dependencies are required.

## Controls

- Drag the landscape to orbit the camera.
- Scroll to zoom.
- Use **Regenerate terrain** to create a new landscape.
- Toggle **Show wireframe** to inspect the terrain mesh.
- Select **Reset view** to restore the starting camera position.
